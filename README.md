# ☕ Java Assignment 5: Interfaces and Abstract Classes

Two Java programs that practice interfaces and abstract classes.

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)

## 📂 Programs

### `Bank.java`
A `BankInterface` with getters and setters for balance and interest rate, implemented by a `Bank` class. The program creates several banks and prints their balances and interest rates.

### `CityBlockConservation.java`
A rainwater-trapping problem: given the heights of city blocks, calculate how much water collects between them. It uses a `WaterConservationSystem` interface, an abstract `RainySeasonConservation` class, and a concrete `CityBlockConservation` implementation.

## 🚀 Running

```bash
javac Bank.java && java Bank
javac CityBlockConservation.java && java CityBlockConservation
```
